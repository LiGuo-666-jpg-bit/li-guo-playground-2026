# 多功能 Unicode/ASCII 编解码器 使用说明

> 适用工具：之前提供的 HTML 网页版编码器/解码器（纯前端，无需联网）

## 1. 工具是什么？

这是一个**支持多种数字进制与文本互相转换**的轻量级工具。它能够：

- 将任意文本（包括中文、英文、特殊符号）转换为对应的 **Unicode 码点**，并以**十进制**、**十六进制（0x）** 或**二进制（0b）** 形式展示。
- 将上述三种进制格式的数字串**还原为原始文本**。

> 注意：本工具基于 **Unicode 码点**（Code Point），而非 UTF-8 字节流。例如中文“纹”的码点是十进制的 `32441`（十六进制 `0x7EB9`）。

---

## 2. 支持的三种编码格式

| 格式 | 示例（字母 A） | 示例（中文“纹”） | 说明 |
| :--- | :--- | :--- | :--- |
| **十进制（Dec）** | `65` | `32441` | 最直观的 Unicode 码点数字 |
| **十六进制（Hex）** | `0x41` | `0x7EB9` | 推荐带 `0x` 前缀，不带也能识别 |
| **二进制（Bin）** | `0b01000001` | `0b0111111010111001` | 推荐带 `0b` 前缀，不带也能识别 |

## 3. 界面与功能按钮

工具界面主要分为三块：

- **① 输入区**：贴入你要处理的**文本**或**数字串**。
- **② 控制按钮区**：五个核心按钮。
- **③ 输出区**：显示转换结果（只读，可手动复制）。

### 按钮功能详解

| 按钮名称 | 功能说明 |
| :--- | :--- |
| **编码为十进制** | 将输入框中的**文本**逐一转为十进制数字（空格分隔）。 |
| **编码为十六进制** | 将输入框中的**文本**逐一转为带 `0x` 前缀的十六进制数字。 |
| **编码为二进制** | 将输入框中的**文本**逐一转为带 `0b` 前缀的二进制数字（补齐 8 位）。 |
| **解码为文本** | 将输入框中的**数字串**（支持十/十六/二进制混合）还原为原始文本。 |
| **清空** | 一键清空输入框和输出框。 |

## 4. 操作示例

### 场景一：把中文句子转成十六进制（用于存储或传输）

1. 在输入框粘贴文本：`欢迎来到新家`
2. 点击 **“编码为十六进制”**
3. 输出区得到：`0x6B22 0x8FCE 0x6765 0x5230 0x65B0 0x5BB6`

### 场景二：把收到的二进制码点还原为文本

1. 在输入框粘贴二进制串：`0b01001100 0b01100101 0b01110110 0b01100101 0b01101100`
2. 点击 **“解码为文本”**
3. 输出区得到：`Level`

### 场景三：混合进制解码（高级用法）

该工具支持**混合输入**，例如粘贴：
`72 101 108 108 111 0x4E16 0x754C 0b01000001`
点击解码后，可正确还原为：`Hello 世界A`

## 5. 快捷操作

- 在输入框中按下 **`Ctrl + Enter`**（Mac 为 `Command + Enter`），等同于点击 **“解码为文本”** 按钮，方便快速还原。

## 6. 注意事项

| 注意点 | 说明 |
| :--- | :--- |
| **码点范围** | 支持十进制 `0` ~ `1114111`（0x10FFFF），即完整的 Unicode 范围。 |
| **中文支持** | 中文直接编码为 Unicode 码点，不会变成乱码或字节序列。 |
| **数字分隔符** | 输入数字串时，可以用**空格、逗号、中文逗号、换行**任意分隔。 |
| **前缀识别** | 十六进制建议加 `0x`，二进制建议加 `0b`，但不强制（如 `7EB9` 也能被识别为十六进制）。 |
| **纯数字歧义** | 纯数字（如 `65`）优先按十进制处理；含 A~F 字母的纯数字串（如 `7EB9`）会被自动识别为十六进制。 |
| **数据隐私** | 本工具为纯前端网页，所有数据仅在本地浏览器中处理，不会上传至任何服务器。 |

## 7. 常见问题（FAQ）

**Q：为什么我编码中文时，得到的数字很大（如 32441）？**  
A：因为中文属于 Unicode 扩展区，码点普遍大于 255，这是正常的。解码时这些数字会准确还原为原汉字。

**Q：我粘贴的数字带 `0x` 或 `0b`，但解码后出现乱码怎么办？**  
A：请检查数字间是否用了正确的分隔符（如空格）。如果数字是连续的（如 `0x410x42`），需要先加空格分开。

**Q：这个工具能解码 Base64 吗？**  
A：不能直接解码 Base64。但您可以将 Base64 解码后的文本粘贴进来，再进行进制转换。
